# HYS NYC CitiBike Transit Analysis

This repository contains data processing and analysis code for HYS's study of CitiBike trips and related built-environment and demographic features in New York City. The pipeline ingests raw datasets (Citibike, census, and NYC Open Data), cleans and aggregates them into H3 hexagon-level features, and produces a combined dataset ready for analysis.

**Quick Start**

- Recommended Python: 3.10+ (use a virtual environment)
- Install dependencies (example):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- Run the full cleaning pipeline and generate intermediate datasets:

```bash
python3 Code/run_pipeline.py
```

**What the pipeline does**

- `Code/run_pipeline.py` executes four processing steps in order:
  - `01_citibike_h3_cells.py` — reads raw Citibike CSVs, filters/cleans rides, maps start/end points to H3 cells, and writes ride and cell outputs.
  - `02_census_and_emp_data.py` — reads Census and LEHD LODES employment files, processes block-level demographics/employment, and maps them to H3 cells.
  - `03_nyc_open_data.py` — ingests NYC Open Data (bike lanes, parks, schools, zoning), converts geometries to H3-cell indicators.
  - `04_merge_data.py` — merges all intermediate datasets to create a combined per-origin-destination H3-cell dataset.

Outputs from the pipeline are saved under `Intermediate/` and `Output/`.

**Data sources & where to place them**

Place raw files under `Data/` using the subfolders below. The processing scripts expect these exact paths.

- Citibike trip CSVs: put all monthly CSVs under `Data/citibike/` (e.g. `202507-citibike-tripdata_1.csv`, ...). Source: https://s3.amazonaws.com/tripdata/index.html
- LEHD LODES employment files and crosswalks: `Data/employment_data/` (e.g. `ny_wac_S000_JT00_2023.csv.gz`, `ny_xwalk.csv.gz`). Source: https://lehd.ces.census.gov/data/lodes/LODES8/ny/
- NHGIS census block tables: `Data/nhgis0001_csv/` (e.g. `nhgis0001_ds258_2020_block.csv`). Source: https://data2.nhgis.org/main

    1. Go to https://data2.nhgis.org/main and create a free IPUMS account if you don't have one.
    2. Use the filters to find tables: Geographic Levels = Block, Datasets = 2020_DHCa.
    3. Add the following tables to your Data Cart:
    * P1 – Total Population
    * P12 – Sex by Age for Selected Age Categories
    * H1 – Housing Units
    4. Open the Data Cart and click Continue.
    5. On the options page, set:
    * Geographic Extents → State → New York
    * Geographic Levels → Block (confirm)
    6. Click Continue, choose CSV as the output format, and submit the request.
    7. Download the extract from the confirmation email or the Extract History page (file will be named something like nhgis0001_ds258_2020_block.csv).

- Census block geography shapefiles: `Data/census_block_geography/` (e.g. `tl_2020_36_tabblock20.shp` and accompanying files). Source: https://www.census.gov/cgi-bin/geo/shapefiles
    1. Go to https://www.census.gov/cgi-bin/geo/shapefiles/index.php?year=2020&layergroup=Blocks+(2020)
    2. Confirm Year = 2020 and Layer type = Blocks, then click Submit.
    3. Select New York from the state list and download the shapefile zip (tl_2020_36_tabblock20.zip).


- NYC Open Data exports: `Data/nyc_open_data/`
  - Bike routes CSV (e.g. `New_York_City_Bike_Routes_YYYYMMDD.csv`). Source: https://data.cityofnewyork.us/dataset/New-York-City-Bike-Routes-Map-/9e2b-mctv
  - Parks Zones (e.g. `Parks_Zones_YYYYMMDD.csv`). Source: https://data.cityofnewyork.us/City-Government/Parks-Zones
  - School locations (e.g. `2019_-_2020_School_Locations_YYYYMMDD.csv`). Source: https://data.cityofnewyork.us/Education/2019-2020-School-Locations
  - NYC Zoning Tax Lot Database (CSV) and MapPLUTO shapefile ZIP for BBL geometry. Source: https://data.cityofnewyork.us/ and https://www.nyc.gov/content/planning/pages/resources/datasets/mappluto-pluto-change

If you download files with different names/dates, place them in the same folders and update the data filenames in code or rename files to match the expected names used in `Code/` scripts.
